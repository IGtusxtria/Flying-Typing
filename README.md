## Tentang Game
Flying Typing adalah game edukasi berbasis web yang dirancang untuk membantu pemain meningkatkan kemampuan mengetik melalui permainan interaktif.

Dalam game ini, pemain harus mengetik kata-kata yang muncul untuk mendapatkan skor dan mempertahankan terbangnya buurng dalam permainan, dan juga setiap kata yang direset akan diberi waktu 4 detik, waktu itu berbentuk burung yang terbang merendah kebawah layar.

## Tujuan Pembelajaran
- Melatih kecepatan mengetik.
- Meningkatkan ketepatan dan akurasi mengetik.
- Melatih konsentrasi dan respons pemain.
- Membiasakan siswa menggunakan keyboard.

## Fitur Game
- 3 tingkat kesulitan: Easy, Normal, dan Hard.
- Pilihan durasi permainan.
- Sistem 5 nyawa.
- Batas waktu untuk setiap kata.
- Statistik kecepatan dan akurasi mengetik.
- Tampilan permainan interaktif.

## Teknologi yang Digunakan
- HTML
- CSS
- JavaScript

## Cara Memainkan
1. Buka game melalui browser.
2. Pilih tingkat kesulitan.
3. Pilih durasi permainan.
4. Ketik kata yang muncul pada layar.
5. Usahakan mengetik dengan cepat dan tepat untuk mendapatkan skor terbaik.

## Tujuan Penggunaan
Game ini dikembangkan sebagai media pembelajaran alternatif untuk membantu siswa mengetik dengan cara yang menyenangkan dan interaktif.
